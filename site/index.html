01 / Install

Put TinyTalk on the board

Use Chrome or Edge on a computer, connect the XIAO by USB, then grant this page access to its serial port.

Install TinyTalk XIAO firmware

The installer writes the full firmware image, including the embedded model, tokenizer, access point, chat server and terminal interface. It replaces the current firmware on the selected board.

Use a XIAO ESP32-S3 Sense. Keep the board connected during flashing. If the browser cannot connect, hold BOOT, tap RESET, release BOOT, then retry.

02 / Connect

Your board becomes the chat server

After flashing, the XIAO starts an access point. Join it from the device you want to chat on, then open the page served by the board.

STEP 01

Join the board Wi-Fi

Choose TinyTalk-XIAO in Wi-Fi settings. Password: needlechat. The access point is local and does not provide internet. This demo uses a published default password; change it before sharing the board.

STEP 02

Open the on-board page

Visit http://192.168.4.1/. This page is served by the XIAO itself; the laptop/phone only displays the interface.

Open board chat ↗

STEP 03

Chat locally

Type a short prompt. The embedded TinyTalk-2 model generates on the microcontroller. Short context and replies help fit the device.

Model limits: TinyTalk-2 is an educational small model, not a general-purpose assistant. Its answers may be incomplete or incorrect. This build uses a short context and caps each response at 24 tokens.
03 / Legacy mode

Prefer a USB terminal?

The same firmware keeps a serial chat loop for command-line users. Close the Arduino serial monitor before starting another client.

# Windows · in the legacy folder py -m pip install pyserial py tinychat.py COM9 # Type /new to clear the short conversation
Download terminal client ↓

Replace COM9 with the XIAO's port in Device Manager. For a ready-to-run helper, download Chat-TinyTalk2.bat.

At a glance

Small on purpose

MODEL

TinyTalk-2 · Q4_0

Embedded in the firmware. No SD card, runtime download, API key, login, or cloud inference.

MEMORY

Sense PSRAM

Uses the XIAO ESP32-S3 Sense's octal PSRAM for the KV cache; internal RAM remains for compute and Wi-Fi.

PRIVACY

Local radio link

Chat text stays between your client and the board over its Wi-Fi access point. The GitHub Pages flasher is only for setup.
